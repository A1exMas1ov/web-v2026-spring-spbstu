Задача 4.
4.1. Создать класс product с полями:
    • id — номер (число)
    • name — название (строка)
    • suppliers — массив имён поставщиков (строки)
Реализовать методы:
    • addSupplier(name) — добавить поставщика
    • removeSupplier(name) — удалить поставщика
    • геттер supplierCount — количество поставщиков
4.2. Дан массив товаров:
    • Группировать товары по поставщикам (поставщик → массив товаров)
    • Получить уникальный список всех поставщиков
    • Вернуть товары с заданным поставщиком
    • Группировать товары по количеству поставщиков
    • Получить товары с максимальным числом поставщиков
4.3. Реализовать пользовательский интерфейс:
    • Список с карточками товаров. Каждая карточка должна содержать: название, список поставщиков, количество поставщиков
    • Кнопки: "Добавить поставщика", “Удалить поставщика”, “Добавить товар”, "Удалить товар"
    • Форма создания товара. Форма добавления поставщика
    • При любых изменениях автоматически обновлять пользовательский интерфейс
    • Все операции добавления/удаления выполнять асинхронно через Promise + setTimeout()
    • Использовать local storage для сохранения текущего списка студентов при закрытии вкладки.
